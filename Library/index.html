    Variables

    Name Description
    m_name the basic gradle dependency specifier.
    m_repositoryURL DEPRECATED URL prefix of the maven repo where the file can be downloaded
    m_absoluteURL DEPRECATED: Prism Launcher-specific absolute URL. takes precedence over the implicit maven repo URL, if defined
    m_filename Prism Launcher extension - filename override
    m_displayname DEPRECATED Prism Launcher extension - display name
    m_hint Prism Launcher-specific type hint - modifies how the library is treated
    m_storagePrefix storage - by default the local libraries folder in Prism Launcher, but could be elsewhere Prism Launcher specific, because of FTB.
    m_hasExcludes true if the library had an extract/excludes section (even empty)
    m_extractExcludes a list of files that shouldn't be extracted from the library
    m_nativeClassifiers native suffixes per OS
    applyRules true if the library had a rules section (even empty)
    m_rules rules associated with the library
    m_mojangDownloads MOJANG: container with Mojang style download info
