    BaseInstance

    class BaseInstance : public QObject, public std::enable_shared_from_this<BaseInstance>

    \brief Base class for instances. This class implements many functions that are common between instances and provides a standard interface for all instances.

    To create a new instance type, create a new class inheriting from this class and implement the pure virtual functions.
